Google Drive를 연결하면 메모는 .md 파일로 자동 저장·동기화됩니다. 옵시디언에서 그대로 열 수 있어요. 마인드맵·타임블록은 같은 폴더의 _mindflow-app.json에 저장돼요.

메모·마인드맵·이미지를 Drive 폴더에 자동 동기화 (모든 기기)
💡 본인 Google 계정으로 로그인 → MindFlow 폴더에 자동 저장 · 이미지는 assets/에 (drive.file 스코프, 본 앱이 만든 파일만 접근)
Drive 폴더 이름은 기존 동기화를 유지하려고 MindFlow(이전 앱 이름) 그대로 둡니다.
고급 · 문제 해결
⚠️ 첨부 파일·이미지 프라이버시: 메모에 붙인 이미지·파일은 표시 속도와 다운로드를 위해 공개 링크(URL을 아는 사람만 접근)로 업로드돼요. 민감한 자료는 첨부 전 한 번 더 확인하세요. 메모 본문(.md)·마인드맵·타임블록 데이터는 본인 Drive에만 비공개로 저장됩니다.
🧹 Drive 정리 도구 — 중복 파일이나 충돌 사본을 발견하면 여기서 정리하세요. 실행 전 자동 백업이 생성됩니다.
본인 OAuth Client ID 사용
기본 Client ID로 자동 연결됩니다. fork해서 자신의 Cloud 프로젝트로 쓰려면 아래 입력란에 직접 붙여넣고 [연결] 누르세요.
